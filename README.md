#  Data Analytics Project
Data analytics project showcasing customer behaviour analysis python, SQL and power BI

##  Overview
This project showcases an end-to-end data analytics workflow, including data exploration, data cleaning, SQL analysis, and dashboard creation. It demonstrates strong skills in Python, PostgreSQL, and Power BI, along with the ability to generate actionable insights from raw data.
